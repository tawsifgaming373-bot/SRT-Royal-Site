# Contributing to SRT Royal Site

Thank you for your interest in contributing to SRT Royal Site! This Site provides guidelines and instructions for contributing.

## Code of Conduct

Please be respectful and professional in all interactions with other contributors.

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Create a new branch for your feature (`git checkout -b feature/YourFeatureName`)
4. Make your changes
5. Commit your changes (`git commit -m 'Add YourFeatureName'`)
6. Push to your fork (`git push origin feature/YourFeatureName`)
7. Open a Pull Request

## Pull Request Process

1. Ensure your code follows the project's style guide
2. Add or update tests if applicable
3. Update the README.md if you've changed functionality
4. Your PR will be reviewed by maintainers
5. Make requested changes and push updates to your branch
6. Once approved, your PR will be merged

## Reporting Bugs

- Use GitHub Issues to report bugs
- Include a clear description of the issue
- Provide steps to reproduce the problem
- Include screenshots or error messages if applicable

## Feature Requests

- Use GitHub Issues for feature requests
- Clearly describe the desired feature
- Explain why this feature would be useful
- Include examples or mockups if possible

## Development Setup

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Check code quality
npm run lint (if available)

# Run tests
npm test (if available)
```

## Coding Standards

- Use consistent indentation (2 spaces)
- Write clear, descriptive variable names
- Add comments for complex logic
- Keep functions small and focused
- Test your changes before submitting

## Questions?

Feel free to open an issue or contact the maintainers. We're here to help!
